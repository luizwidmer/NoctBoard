# Support

Noct Board is pre-1.0, small-swarm evaluation software. It has no production
support SLA, hosted service, managed relay, account system, or recovery service.

Use a public issue for reproducible bugs and scoped feature requests that can be
described with synthetic data. Search existing issues first and include the
Noct Board commit, macOS/Apple-silicon environment, Swift version, and the
smallest safe reproduction.

Do not post vulnerabilities, keys, relay capabilities, passwords, client state,
admission artifacts, board text, audit exports, or identifying transport
metadata. Follow [SECURITY.md](SECURITY.md) for private reporting.

Operational help is best effort. The maintainer cannot restore lost keys,
expired routes, removed-member history, missing admission sidecars, or boards
that exceeded the v1 retained-event window.
